# Laboratorio: Orquestación de Contenedores y Microservicios con Docker Compose

Este repositorio contiene la solución completa del laboratorio enfocado en la orquestación de servicios mediante **Docker Compose**, gestión de redes internas, persistencia de datos mediante volúmenes nombrados, externalización de variables de entorno y control de salud (*healthchecks*) de contenedores.
